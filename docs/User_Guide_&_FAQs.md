NumPy — User Guide & FAQs
1. Introduction

NumPy is a simple daily activity tracking application.

It helps users keep track of:

Meals

Water

Steps

Weight

Sleep

Exercise

Mood

The application is designed to make daily logging quick and simple.

2. Getting Started

When NumPy is opened for the first time, the application will guide the user through a short setup.

The user may be asked for:

Display name

Activities to track

Daily goals

Notification preferences

These settings can be changed later.

3. Installing NumPy
3.1 iPhone / iPad

If NumPy is opened in Safari:

Open NumPy in Safari.

Tap the Share button.

Select Add to Home Screen.

Confirm by selecting Add.

Open NumPy from the Home Screen.

The application will then open in an app-like standalone experience where supported.

3.2 Android

Depending on the browser:

Open NumPy.

Open the browser menu.

Select the installation or Add to Home Screen option.

Confirm the installation.

The exact wording may differ between browsers.

3.3 Desktop

If the browser supports PWA installation:

Open NumPy.

Select the browser's installation option.

Confirm the installation.

If installation is not supported, NumPy can still be used as a normal website.

18. Frequently Asked Questions
Is NumPy a mobile application?

NumPy is a Progressive Web Application.

It runs through a web browser but can be installed on supported devices and opened like an application.

Do I need to install an APK?

No.

NumPy does not require an Android APK or an iOS application package.

It is installed as a PWA.

Does NumPy work without installation?

Yes.

NumPy can be used directly through a supported web browser.

Can I remove NumPy?

Yes.

Because NumPy is a PWA, it can be removed from the device in the same general way as other installed web applications.

Can the companion change my activity records?

By default, the companion is intended to have read access to shared activity information.

The primary user's records remain under the primary user's control unless a specific feature explicitly grants editing permission.

Can I turn off reminders?

Yes.

Notification preferences can be changed from Settings.

Device-level notification permissions may also need to be changed.

Are calorie values exact?

No.

Calories are estimates and can vary based on food, preparation, ingredients, and portion size.

Can I change my daily water goal?

Yes, provided the feature is enabled in Settings.

Can I change my step goal?

Yes, provided the feature is enabled in Settings.

Can I skip an activity?

Yes.

The application should not treat a missed activity as a failure.

Can I restart the application tour?

Yes.

The tour can be restarted from Settings.

What happens if I skip onboarding?

The application can still be used.

Relevant setup options can be configured later.

What happens if I lose internet access?

The application may continue to display cached information.

Offline write support depends on the current version.

The application should clearly indicate when a record has not yet synchronized.

Can I delete my data?

The production application should provide a supported data deletion process.

Deletion should remove or anonymize associated records according to the application's data retention policy.

Is NumPy a medical application?

No.

NumPy is a personal activity tracking application.

It should not be used to diagnose, treat, or monitor a medical condition.

19. Troubleshooting
NumPy Does Not Open

Check:

Internet connection.

Browser compatibility.

Whether the application is currently available.

Whether the browser is blocking required storage or scripts.

Notifications Do Not Appear

Check:

Browser notification permission.

Device notification settings.

NumPy notification settings.

Notification schedule.

Whether the browser supports the required notification functionality.

NumPy Does Not Appear After Installation

Check the device Home Screen or application launcher.

If necessary, repeat the browser's Add to Home Screen or installation process.

My Activity Was Not Saved

Check:

Internet connection.

Whether the user is still signed in.

Whether the application displays an error.

Whether the activity appears after refreshing.

Do not repeatedly submit the same activity if the application indicates that it is already being synchronized.
